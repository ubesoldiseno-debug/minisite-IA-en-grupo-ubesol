Guía rápida para empezar con IA

Conceptos breves y útiles para que cualquier persona entienda ChatGPT antes de usar las herramientas.

Concepto base

¿Qué es la IA?

La IA es tecnología capaz de aprender patrones, razonar sobre información y ayudarte a resolver tareas. En la práctica, sirve para redactar, resumir, analizar, clasificar, idear y automatizar trabajo repetitivo.

Idea rápida: no sustituye tu criterio. Lo acelera cuando le das buen contexto.
Herramienta

¿Qué es ChatGPT?

ChatGPT es un asistente conversacional de OpenAI basado en un LLM, es decir, un modelo de lenguaje de gran tamaño, como Gemini de Google o Claude de Anthropic. Le escribes una petición y te devuelve una respuesta útil en lenguaje natural para pensar, escribir, resumir, revisar o generar primeras versiones.

Úsalo para: ganar velocidad, ordenar ideas y reducir tiempo en tareas de bajo valor repetitivo.
Clave de uso

¿Qué es un prompt?

Un prompt es la instrucción que le das a ChatGPT. Cuanto más claro seas con el objetivo, el contexto, el tono y el formato, mejor será la respuesta.

Ejemplo: “Resume esta reunión en 5 puntos, indica riesgos y cierra con 3 acciones prioritarias.”
Diferencia importante

GPT vs Project en ChatGPT

Ambos sirven para trabajar mejor, pero no son lo mismo. Uno está pensado como asistente especializado; el otro, como espacio de trabajo con contexto.

GPT Es una versión personalizada de ChatGPT para una tarea concreta. Ideal cuando quieres una herramienta ya preparada para usarla una y otra vez.
Project Es un espacio donde agrupas conversaciones, archivos e instrucciones del mismo tema. Ideal para trabajos continuos, seguimiento y contexto acumulado.
Consejos rápidos

Cómo sacarle partido

  • Sé específico con lo que quieres conseguir.
  • Da contexto antes de pedir una respuesta.
  • Pide formato: lista, tabla, email o resumen.
  • Itera: una segunda versión casi siempre mejora la primera.
  • Verifica siempre datos sensibles o críticos.

Diccionario básico de términos de IA

Un glosario claro para familiarizarse con los conceptos más habituales de inteligencia artificial y ChatGPT.

Conceptos esenciales

Lo mínimo que conviene conocer

IA

Tecnología que permite a las máquinas realizar tareas que normalmente asociamos con la inteligencia humana.

IA generativa

Tipo de IA capaz de crear contenido nuevo, como texto, imágenes, audio o código.

Modelo

El motor de IA que procesa una petición y genera una respuesta.

LLM

Siglas de modelo de lenguaje de gran tamaño. Es la base de herramientas como ChatGPT, Gemini o Claude.

ChatGPT

Asistente conversacional basado en un LLM, pensado para escribir, analizar, resumir, idear o resolver tareas.

GPT

Puede referirse al modelo de lenguaje en sí o, dentro de ChatGPT, a un asistente personalizado para una función concreta.

GPT personalizado

Versión configurada para hacer una tarea específica, con instrucciones, tono y comportamiento definidos.

Proyecto

Espacio de trabajo dentro de ChatGPT donde agrupas chats, archivos e instrucciones para mantener contexto.

Prompt

Instrucción, pregunta o petición que escribes para que la IA te responda.

Contexto

Información adicional que das al modelo para que entienda mejor lo que necesitas.

Chat

Conversación concreta que mantienes con la IA dentro de una herramienta como ChatGPT.

Multimodal

Sistema que puede trabajar con varios tipos de entrada o salida, como texto, imagen, audio o documentos.

Token

Pequeña unidad de texto que usa el modelo para leer, interpretar y generar contenido.

Ventana de contexto

Cantidad de información que el modelo puede tener en cuenta al mismo tiempo dentro de una conversación.

Memoria

Capacidad de una herramienta para recordar información útil entre interacciones, según la configuración disponible.

Uso práctico

Términos que verás al trabajar con prompts

Rol

Papel que le asignas a la IA en un prompt, por ejemplo analista, redactor o experto en marketing.

Formato de salida

Manera en la que quieres recibir la respuesta, por ejemplo lista, tabla, email, resumen o pasos.

Ejemplo

Muestra que das a la IA para que entienda mejor el estilo o resultado que buscas.

Iterar

Mejorar el resultado en varias rondas, ajustando el prompt o afinando la respuesta.

Automatización

Uso de IA para hacer tareas repetitivas con menos intervención manual.

Agente

Sistema de IA que no solo responde, sino que también puede ejecutar pasos, buscar información o usar herramientas para lograr un objetivo.

Flujo de trabajo

Secuencia de pasos para completar una tarea de forma ordenada, repetible y más eficiente.

Resumen

Versión reducida de un contenido, manteniendo las ideas clave y lo importante.

Extracción de información

Proceso de sacar datos concretos de un texto, PDF, tabla o documento.

Clasificación

Acción de ordenar o etiquetar información según categorías o criterios definidos.

Transcripción

Conversión de audio o vídeo en texto para poder revisarlo, resumirlo o reutilizarlo.

OCR

Tecnología que detecta y extrae el texto que aparece dentro de imágenes o documentos escaneados.

Calidad y nivel medio

Conceptos para usar la IA con más criterio

Alucinación

Respuesta inventada o incorrecta que la IA presenta como si fuera cierta.

Sesgo

Tendencia del sistema a responder con ciertas inclinaciones o errores por los datos con los que fue entrenado.

Validación

Revisión humana para comprobar que una respuesta es correcta antes de usarla.

Fuente

Documento, web o referencia en la que se apoya una afirmación o un dato.

Cita

Mención explícita de la fuente de donde sale una idea, un dato o una afirmación.

Dataset

Conjunto de datos usado para entrenar, probar o evaluar un modelo.

Entrenamiento

Fase en la que el modelo aprende patrones a partir de grandes cantidades de datos.

Inferencia

Momento en el que el modelo ya entrenado genera una respuesta a tu prompt.

Fine-tuning

Ajuste adicional de un modelo con ejemplos específicos para orientarlo mejor a una tarea concreta.

RAG

Técnica que combina un modelo con documentos o fuentes externas para responder con más contexto y precisión.

Embedding

Representación numérica de un texto que permite comparar significado o similitud.

Base vectorial

Sistema que guarda embeddings para localizar información parecida de forma rápida.

Temperatura

Ajuste técnico que influye en si una respuesta sale más creativa o más predecible.

Precisión

Grado en que una respuesta se ajusta a lo que pediste y a la realidad.

Prompt engineering

Forma de diseñar mejor las instrucciones para obtener resultados más útiles, claros y consistentes.
